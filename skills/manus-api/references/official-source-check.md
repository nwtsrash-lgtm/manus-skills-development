# مصادر التحقق الرسمية

**آخر مراجعة لهذه الصفحة:** 2026-08-13. استخدم الروابط التالية للتحقق من المعلومات المتغيرة قبل اعتماد تكامل أو مثال أو حد تشغيلي.

| الموضوع | المصدر الرسمي | ما يجب التحقق منه |
|---|---|---|
| مقدمة API v2 | https://open.manus.ai/docs/v2/introduction | عنوان الأساس والإصدار ومفاهيم البدء. |
| المصادقة | https://open.manus.ai/docs/v2/authentication | أساليب المصادقة وقيود endpoint والنطاقات. |
| دورة المهمة | https://open.manus.ai/docs/v2/task-lifecycle | أحداث الحالة والانتظار ومسار السؤال مقابل التأكيد. |
| المخرجات المنظمة | https://open.manus.ai/docs/v2/structured-output | مخطط JSON المدعوم ودورة التسليح والنتيجة والفشل. |
| Webhooks | https://open.manus.ai/docs/v2/webhooks-overview | عقد الاستقبال ووقت الاستجابة وأنواع الأحداث. |
| أمان Webhooks | https://open.manus.ai/docs/v2/webhooks-security | طريقة التحقق من التوقيع والتعامل مع إعادة التسليم. |
| Open App | https://open.manus.ai/docs/v2/open-app | OAuth، التفويض، والنطاقات المتاحة. |

لا تستبدل وثيقة endpoint بالتلخيص الموجود هنا. إذا اختلفت الوثائق الخارجية عن الملفات المضمنة، سجّل الفرق، وحدّث الفهرس والاختبارات التي تتأثر، ثم راجع التغيير قبل النشر.
