# تكامل البيانات الخارجية

## مسار الاختيار

ابدأ بالبحث في Manus API Hub باستخدام بحث API للتحقق من وجود موفر مدمج مناسب. إذا وُجد موفر مناسب، اقرأ عقده ومتطلبات المصادقة والحدود قبل البرمجة. لا تضف API خارجيًا لمجرد وجود SDK مألوف إذا كان الموفر المدمج يحقق الحاجة بوضوح.

استخدم تكاملًا خارجيًا فقط عندما لا يغطي API Hub البيانات أو التحديث أو الترخيص المطلوب. افصل مصدر البيانات عن واجهة المستخدم حتى يمكن استبداله أو تعطيله من دون إعادة كتابة المكونات.

| الحاجة | المسار |
|---|---|
| عرض بيانات عامة قليلة التغير | API Hub أو endpoint خادمي مع cache قصير. |
| بيانات تتطلب مفتاحًا أو منطقًا تجاريًا | إجراء خادمي أو tRPC؛ لا تستدعها من العميل. |
| عملية كثيفة أو دفعات أو مزامنة دورية | خادم أو مهمة مجدولة مع idempotency ومراقبة. |
| بيانات يملكها المستخدم داخل التطبيق | قاعدة بيانات التطبيق، لا مصدرًا خارجيًا في كل عرض. |

## التنفيذ

1. عرّف الحد الأدنى من الحقول التي يحتاجها المنتج، والتحويل من استجابة المصدر إلى نموذج داخلي ثابت.
2. ضع الطلب في طبقة خادمية. خزّن مفتاح المصدر في إعداد خادمي أو connector، ولا ترسله إلى تطبيق الويب أو الهاتف أو سجل التشخيص.
3. تحقق من المدخلات وحدود الصفحة أو التاريخ أو الكمية قبل الطلب. استخدم timeout، وحدًا للمحاولات، وتراجعًا متدرجًا فقط للأخطاء المؤقتة.
4. طبّق cache بمفتاح واضح ومدة مناسبة لطبيعة البيانات، وسجل وقت آخر تحديث ومصدره. لا تعامل cache قديمًا كمعلومة لحظية.
5. اعرض حالة تحميل وبيانات قديمة مع وسم زمني أو رسالة فشل قابلة للتصرف؛ لا تملأ الواجهة بقيم مخترعة عندما يفشل المصدر.

## الأخطاء والحدود

ميّز بين 400 الناتج عن مدخل غير صحيح، و401/403 الناتج عن مصادقة أو تفويض، و404 الناتج عن معرف مفقود، و429 أو 5xx الناتج عن حد أو عطل مؤقت. لا تعيد محاولة 4xx غير القابل لإعادة المحاولة. عند 429، احترم تعليمات الموفر وقلل الطلبات أو استخدم cache؛ لا تخلق حلقة إعادة محاولة مفتوحة.

تحقق من الترخيص وشروط الاستخدام للبيانات التي ستخزنها أو تعرضها أو تعيد نشرها. لا تسجل حمولة كاملة إذا احتوت بيانات مستخدم أو مفاتيح أو معلومات حساسة.

## التحقق

اختبر حالة نجاح، ومدخلًا غير صحيح، وانتهاء مهلة أو 429، ومصدرًا يعيد حقولًا ناقصة. تأكد أن المكونات لا تعرف مفتاح المصدر وأن الاستجابة تمر عبر نموذج داخلي يمكن فحصه. اذكر للمستخدم مصدر البيانات ووقت التحديث عندما تؤثر الحداثة في القرار أو العرض.
