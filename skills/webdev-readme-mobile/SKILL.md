# قالب WebDev Mobile

## قرار الاستدعاء

استخدم هذا الدليل عند تعديل شاشات Expo أو التنقل أو الحالة أو الميزات الأصلية أو واجهة هاتف تستهدف iOS وAndroid. اقرأ `webdev-readme-mobile-backend` عندما تحتاج بيانات محمية أو قاعدة بيانات أو API، واستخدم أدلة التكامل المتخصصة للوسائط أو LLM أو الملفات بعد تحديد الطبقة المناسبة.

## سير العمل

1. حدّد الشاشة ونوع بياناتها وسلوكها على الشاشات الصغيرة وحالات الاتصال أو عدمه قبل كتابة المكونات.
2. استعمل بنية المشروع ومكونات الحاوية والتنقل الموجودة، ولا تنشئ نظام تنقل أو theme موازيا بلا سبب.
3. صمّم حالات التحميل والفراغ والفشل والنجاح، ثم تحقق من اللمس والحجم وإتاحة القراءة على هاتف صغير.
4. ضع الأسرار والمنطق الحساس وعمليات البيانات في الخلفية؛ لا تعتمد على أن إخفاء مكون في التطبيق يحمي موردًا.
5. اختبر مسارًا ناجحًا، رفض تفويض، إدخالًا غير صالح، وفشل شبكة أو خدمة قبل التسليم.

## قرار سريع

| الحاجة | المرجع أو المسار |
|---|---|
| هيكل شاشة أو تنقل أو styling | `references/template-guide.md` في أقسام البنية والتصميم. |
| بيانات ومصادقة أو API | `webdev-readme-mobile-backend`. |
| صوت أو صور أو ملفات | مهارة التكامل الخاصة ثم قسم القدرات في المرجع. |
| سلوك أصلي أو منصة | قسم Native Features في المرجع. |
| عطل واجهة أو crash | قسم pitfalls والتشخيص في المرجع. |

## السلامة والتحقق

لا تضع مفاتيح أو أسرارًا أو أدوار صلاحية في التطبيق العميل باعتبارها حماية. تحقق من تفويض كل عملية حساسة في الخلفية، وقلل البيانات التي تخزن محليًا. عند فشل بناء أو اعتماد أصلي، اقرأ رسالة الخطأ ونقّح الإعداد أو النسخة بدل تغيير حزم عشوائيًا.

## المرجع التفصيلي

اقرأ `references/template-guide.md` عند الحاجة إلى أسماء الملفات أو تفاصيل Expo وNativeWind والحالة والتصميم والميزات الأصلية والتسليم. احتفظ بهذه النواة قصيرة، ولا تنقل إليها تفصيلًا خاصًا بمنصة أو حزمة ما لم يغيّر قرار التنفيذ.
